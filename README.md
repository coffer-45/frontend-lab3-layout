# Лабораторна робота №3 — блочна верстка макета

Виконав: **Вовк Андрій Андрійович**, група **ІО-41**. Номер у загальному списку — **67**.

У ЛР №3 є 10 зразків, тому за формулою зі слайда 9 вступної лекції варіант — **7**: `(67 - 1) % 10 + 1 = 7`. Макет наведено на с. 17 PDF методички. Його структура: текстова смуга на всю ширину; посередині зображення зліва (75%) і текст справа (25%); знизу зображення на всю ширину.

**Код:** https://github.com/coffer-45/frontend-lab3-layout

**Float:** https://coffer-45.github.io/frontend-lab3-layout/

**Flexbox:** https://coffer-45.github.io/frontend-lab3-layout/flex.html

## Запуск

Відкрийте локально `index.html` і `flex.html` у браузері. Для статичних сторінок не потрібні сервер, збірка чи залежності. Вебшрифти підтягуються з Google Fonts; без мережі використовуються системні шрифти.

## Файли й підходи

- `index.html` — завдання 1, версія макета з `float`;
- `flex.html` — завдання 2, той самий макет і той самий вміст із Flexbox;
- `style.css` — спільне оформлення; середній ряд у `.float-layout` використовує `float: left`, **`width: 75%` і `width: 25%`** та clearfix, а в `.flex-layout` — `display: flex`, `flex-basis: 75%` і `25%`;
- `mukachevo-center.jpg` — фото, використане в обох зонах зображень із різним CSS-кадруванням і кольоровими ефектами;
- `float-screenshot.png`, `flex-screenshot.png` — скриншоти обох реалізацій для звіту; `page-float.png`, `page-flex.png` — повні скриншоти сторінок;
- `lab3.typ` — вихідний файл звіту; `lab3.pdf` — звіт у форматі PDF.

На екранах до 760 px обидва середні блоки переходять в одну колонку. Версії можна порівняти через посилання в шапці сторінки.
